[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](./LICENSE)

Этот репозиторий является частью учебного задания по предмету «Системотехника строительства» НИУ МГСУ. 

Полный текст задания можно прочесть [здесь](Задание.md).

## Требования

- Python 3.11+
- UV (https://docs.astral.sh/uv/)

## Сборка и запуск

```bash
git clone https://github.com/ivan-r-sigaev/layoff_calculator.git
cd layoff_calculator
uv sync
uv run ./src/layoff_calculator
```
